# Mio i125S Beginner Blog

A ready-to-deploy static SEO-optimized blog for the ITP105 website/blog activity.

## Files
- `index.html` – home page
- `about.html` – about page
- `contact.html` – contact page
- `posts/` – five 300+ word blog posts
- `assets/style.css` – responsive styling
- `assets/script.js` – mobile menu + current year
- `sitemap.xml` – basic sitemap
- `robots.txt` – crawler instructions
- `seo-documentation.md` – keywords, intent, titles, meta descriptions, slugs

## Before submitting
1. Replace `student@example.com` in `contact.html` with your actual email address.
2. Check every page locally, then deploy to GitHub Pages, Netlify, Vercel, or another allowed host.
3. Open the deployed URL in a private/incognito window.
4. Keep the website public until grading is finished.
5. Update the URLs in `sitemap.xml` after deployment.
